# Aikon Automations Hostinger Package

This folder is a standalone website package prepared for standard Hostinger hosting.

## Before upload

1. Update business contact details inside `assets/js/site.js`
2. Update the recipient email inside `contact.php`
3. If your live domain is not `https://aikonautomations.com`, update:
   - canonical URLs in the HTML files
   - `sitemap.xml`
   - `robots.txt`

## Upload steps for Hostinger

1. Open Hostinger hPanel
2. Go to `File Manager`
3. Open your domain's `public_html` folder
4. Upload all contents of this folder into `public_html`
5. Make sure `index.html`, `.htaccess`, `contact.php`, `assets`, and `services` are all present

## SEO launch checklist

1. Connect your domain to Google Search Console
2. Submit `https://aikonautomations.com/sitemap.xml`
3. Connect Google Analytics or another analytics platform
4. Create and optimize your Google Business Profile if you serve a local market
5. Build backlinks, case studies, testimonials and regular supporting content

## Important note

This website has a strong on-page SEO foundation, but no website can honestly guarantee a number one search position. Long-term ranking depends on competition, backlinks, domain trust, page quality and ongoing content activity.
