# Tatva Law LLP Website

This is a static multi-page website built for direct upload to Hostinger or any standard shared hosting setup.

## Pages

- `index.html` - home page
- `about.html` - firm profile page
- `practice-areas.html` - practice areas page
- `contact.html` - contact page
- `styles.css` - shared styling for all pages
- `script.js` - shared navigation and reveal effects
- `assets/favicon.svg` - site icon

## Hostinger Upload

1. Open your Hostinger hosting panel.
2. Go to `File Manager`.
3. Open the `public_html` folder for your domain.
4. Upload all files and folders from this project into `public_html`.
5. Make sure `index.html` stays in the root of `public_html`.
6. If Hostinger already has a default `index.html`, replace it with this one.

## Edit Content Later

- Main page content is in `index.html`, `about.html`, `practice-areas.html`, and `contact.html`
- Colors, layout and responsive styling are in `styles.css`
- Navigation behavior and reveal effects are in `script.js`
- Contact links can be updated directly inside the HTML pages

## Public Details Used

The site content and business details were arranged from the firm information publicly visible through the provided Google Maps listing, related public business listing mirrors, and public company record references available at the time of creation.
